# 验收测试用例

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| T01 | 注册普通用户，尝试访问 `/api/admin/dashboard` | 返回 403；密码只以 BCrypt 哈希存储 |
| T02 | 管理员禁用用户后，该用户使用旧令牌 | 下次请求无法通过鉴权 |
| T03 | 管理员设置会员到期时间，随后将其取消 | 有效期内可读取 VIP 完整音频，取消后只能读取试听对象 |
| T04 | 非会员以 `Range` 请求 VIP 音频任意片段 | 范围只针对独立 30 秒试听对象，不会泄露完整音频 |
| T05 | 歌曲下架后检索、封面和音频请求 | 用户曲库不出现；资源接口拒绝读取 |
| T06 | 首次导入 506 个 `.mp3` 文件对应的清单，再重复导入 | 504 条 `matched` 中 43 个 HTML 伪音频被拒绝，仅 461 首有效歌曲公开；两条 `review` 记录跳过；重跑不重复建歌 |
| T07 | 用户收藏、取消收藏；创建歌单并增删歌曲 | 数据正确更新；无法操作他人歌单 |
| T08 | 用户提交评论，管理员审核 | 审核前公开列表不可见，通过后可见 |
| T09 | 播放不到 10 秒、超出可播放时长、30 秒内重复上报 | 不计入有效播放或按去重规则处理 |
| T10 | 无行为新用户请求两种推荐 | 返回可播放的热门歌曲；每日任务完成后生成新列表 |
| T11 | 公开数据集实验重复执行 | 固定划分、固定指标；存储的算法与数据集名称清晰 |
| T12 | AI 多轮查询“雨天温柔中文歌”后追问“更轻快” | 会话留存；仅返回本地已上架曲目 |
| T13 | DeepSeek 未配置、超时或输出异常 | 返回可重试错误，保留失败记录，不生成虚构歌曲 |
| T14 | 列表页码为负、大小超过 100 | 页码修正为 1，单页上限 100 |
| T15 | 上传扩展名为 `.mp3`、内容为 HTML 的文件 | 返回 400，不写入数据库或 MinIO |

单元测试位于 `code/src/test`，覆盖标签排序、协同过滤、冷启动、VIP 音频范围权限、会员状态读取和无效音频拦截。本机已完成 Docker、FFmpeg 和 DeepSeek 多轮查歌的冒烟验证；换用其他模型或重新部署时仍需复测外部 API。
