# 声屿音乐 · Vue 3 前端

默认页面连接 Spring Boot 后端，支持登录、曲库、播放、收藏、歌单、推荐、AI 查歌和管理操作。第一阶段的静态设计稿仍可通过 `?prototype=1` 查看，使用模拟数据。

## 运行

```bash
cd ui
npm install
npm run dev
```

浏览器使用 `http://localhost:5173` 打开页面。开发服务器会将 `/api` 转发至 `http://localhost:8080`；后端默认仅允许 `http://localhost:5173` 作为跨域来源，因此不要将本机地址改成 `127.0.0.1`。请先按 `../code/README.md` 启动后端及依赖。页面左侧可切换用户端；管理员登录后可看到管理端入口，移动端使用顶部菜单。

## 页面范围

- 用户端：首页、曲库检索、播放页、每日推荐、AI 查歌、收藏、歌单、播放历史、会员状态
- 管理端：数据看板、用户会员、歌曲管理、评论管理

实际音频由后端读取 MinIO；VIP 非会员只能获得独立试听文件。未设置 DeepSeek Key 时，AI 查歌会显示服务未配置。

收藏和播放历史支持分页；管理端支持用户、歌曲和评论筛选，统计页显示近七天播放量、曲风分布及推荐实验结果。播放器会取消被快速切歌淘汰的音频请求，登录失效时停止播放并清除个人页面数据。
